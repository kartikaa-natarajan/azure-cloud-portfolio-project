## 🚀 Getting Started

### Prerequisites

No build tools or package managers required — this is a **pure static website**.

### Run Locally

1. **Clone the repository**

   ```bash
   git clone https://github.com/kartikaa-natarajan/azure-cloud-portfolio-project.git
   cd azure-cloud-portfolio-project/portfolio-shivam
   ```

2. **Open in browser**

   Simply open `index.html` in your preferred browser:

   ```bash
   # macOS
   open index.html

   # Linux
   xdg-open index.html

   # Windows
   start index.html
   ```

   Or use a local development server for the best experience:

   ```bash
   # Using Python
   python -m http.server 8080

   # Using Node.js (npx)
   npx serve .
   ```

3. **Visit** `http://localhost:8080` in your browser.
